# Brunstreg

Mobilvennleg PWA for å registrere og følgje opp brunst hos storfe.

## Funksjonar

- Kuregister med individnummer, namn, fødselsdato og siste kalving
- Rask registrering av brunstteikn med automatisk tidspunkt
- Dashboard med kyr som bør følgjast opp i dag
- Fargestatus, estimert neste brunst og rettleiande insemineringsvindauge
- Historikk for observasjonar, inseminering, drektigheit og kalving
- Lokal lagring på eininga og eksport/import av sikkerheitskopi
- Installerbar og tilgjengeleg utan nett etter første opning

## Viktig

Appen er eit praktisk hjelpemiddel, ikkje ei veterinærfagleg avgjerdsstøtte. Insemineringstidspunkt avheng mellom anna av brunstforløp og sædtype. Følg råda frå Geno, veterinær eller inseminør.

## Publisering

Statisk nettapp. Kan publiserast direkte med GitHub Pages frå rotmappa på `main`.
